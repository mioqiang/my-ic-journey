# 学习路线 · 数字 IC 后端（主攻）＋ 前端/验证（扩面）

> **本仓库只记录学习路线本身**：学什么、怎么学、学到什么程度算合格。
> 不存放代码、项目、工程文件、周志或过程记录。
> 集成电路科学与工程 硕士在读（2026.09–2029.06）

## 一、方向与定位

| 优先级 | 方向 | 说明 |
|---|---|---|
| **主攻** | **数字 IC 后端**（PR / STA / 物理验证） | 专业名直接对口；日常工作本质是「跑工具 → 看报告 → 修 violation → 写脚本自动化」，更看重流程熟练度与脚本能力，不像前端设计那样要求深厚的架构功底 |
| 扩面 | **数字前端 / 验证** | 扩大投递面。重点打**后端相关验证岗**：物理验证（DRC/LVS）、STA 签核、DFT、形式验证、后端工具 AE —— 竞争比通用 UVM 岗位小，且后端经验直接是入场券 |
| 保底 | 嵌入式 / 硬件 | C / STM32 / RTOS，与后端共享 Linux 地基 |
| 延伸 | 半导体工艺 | 课题背景与湿法工艺、电化学量测、ECP 电镀直接相关 |

### 1.1 为什么这样选

1. **后端是可以靠高强度训练补齐的方向。** 学校没有商业 EDA 工具（ICC2 / Innovus），但开源全流程（OpenROAD / OpenLane + Sky130 PDK）能完整跑通 RTL-to-GDS，这就是替代方案。
2. **后端与嵌入式共享 Linux 地基**，前期可以合并投入。
3. **半导体不用单独开一条学习线**：直接用电化学背景去投设备 / 量测公司，课题对应 ECP 电镀、CMP、湿法工艺、电化学量测。
4. **注意**：后端正在被自动化（ML 驱动的 PPA 优化），基础执行岗会减少。因此定位不能停在「会用工具」，必须做到**能解释物理成因、能写自动化流程**。

### 1.2 分阶段策略（关键）

三个方向到「可面试」分别需要约 5 / 6–8 / 6–9 个月，**不可能同时完成**，必须错峰推进：

| 阶段 | 时间 | 目标 | 可面试的方向 |
|---|---|---|---|
| **P1** | 2026.10–2027.02 | 后端打通 + 验证入门 | 后端 ✅；验证仅「基础题能答」 |
| **P2** | 2027.03–2027.06 | 研一下实习 | 后端 ✅ |
| **P3** | 2027.07–2027.09 | 研二暑假实习 | 后端 ✅；验证 ⚠️ 冲击 |
| **P4** | 2027.09–2028.06 | 补前端设计 + UVM 系统化 | 三条线全开 |
| **P5** | **2028.07–2028.12** | **秋招（主战场）** | 三条线全部可面试 |

> **核心认知**：研一下的实习用来拿到「工业经历」这个标签；**2028.07 秋招才是决战场**，那时还有一年半时间把三条线都补齐。

### 1.3 投递分层

| 层级 | 数量 | 精力占比 | 说明 |
|---|---|---|---|
| 冲刺层（大厂） | ≤20 家 | 少量 | 投，但不投入主要精力 |
| **匹配层（中小 IC / 设计服务 / EDA 服务）** | **≥40 家** | **重点** | 最可能拿到机会的地方 |

## 二、能力清单（验收标准）

### A. 数字 IC 后端 —— 主攻

**必须会（缺一不可）：**

- [ ] **Linux 命令行**：文件 / 权限 / 进程 / `grep` / `sed` / `awk` / 管道 / 重定向 / `vim` / `ssh` / `rsync`
- [ ] **Tcl 脚本**：变量、列表、控制流、`proc`、字符串、正则、文件读写 —— ICC2 / Innovus 的脚本语言
- [ ] **Python 或 Perl 基础**：写自动化脚本处理报告
- [ ] **数字电路基础**：组合 / 时序逻辑、触发器、状态机、时钟
- [ ] **Verilog**：能读懂、能写模块、能写 testbench
- [ ] **STA 时序基础**：setup/hold、arrival/required、slack、时钟偏斜、SDC 约束（`create_clock`、`set_input_delay`）
- [ ] **后端全流程概念**：综合 → floorplan → placement → CTS → routing → 时序优化 → DRC/LVS → 签核
- [ ] **一个跑通的 RTL-to-GDS 全流程**（OpenROAD / OpenLane + Sky130 PDK）

**必须知道的物理专题（面试高频深挖，也最容易拉开差距）：**

- [ ] **IR drop**：静态 vs 动态、电源网格拓扑、strap 宽度与间距、为什么宏单元附近更严重
- [ ] **电迁移 EM**：Black 方程 `MTTF = A·J⁻ⁿ·exp(Ea/kT)`、为什么 via 是薄弱点、温度的影响
- [ ] **电源完整性 PDN**：PDN 阻抗、谐振、decap 的作用与放置原则
- [ ] **能解释「为什么」而不是「教程这样写」**：利用率取值理由、拥塞成因、WNS 收敛手段、关键路径的物理瓶颈

**加分项：**

- [ ] 第二个更复杂的设计（UART/SPI 控制器、小型 RISC-V 核）
- [ ] 会用 OpenSTA / Yosys / Magic / Netgen / PDNSim
- [ ] 懂 PPA 权衡、工艺角（TT/FF/SS）、多阈值电压
- [ ] 懂拥塞、IR drop、串扰、时钟树结构
- [ ] 了解商业工具（ICC2 / Innovus）的命令与流程概念
- [ ] 有 FPGA 上板经验（Vivado 综合 + 时序报告）

### B. 数字前端 / 验证 —— 扩面

**研一阶段（到 2027.02）只要求：**

- [ ] SystemVerilog 基础：`logic`/`bit`、`always_comb`/`always_ff`、`class`、`rand`/`randc`、`constraint`、`randomize()`
- [ ] `interface` / `modport` / `clocking block` 的作用
- [ ] **UVM 概念能讲清**：component 层次（test → env → agent → driver/monitor/sequencer）、`uvm_sequence_item`、config_db、factory 覆盖、覆盖率类型、scoreboard 作用
- [ ] 在 EDA Playground 跑通一个最小 UVM 例程

**研二阶段（P4）才要求：**

- [ ] 完整 UVM 项目：一个模块的验证环境 + 覆盖率收敛 + 回归
- [ ] 一个完整的数字设计：架构 → RTL → 验证 → 综合 → 时序收敛

**重点投递方向（不要用通用 UVM 去和科班学员正面竞争）：**
物理验证 PV（DRC/LVS/ERC/DFM）、STA 签核、DFT、形式验证、后端工具 AE/FAE、PDN 分析

### C. 嵌入式 / 硬件 —— 保底

- [ ] **C 语言**：指针、结构体、位操作、**环形缓冲区 / 状态机 / 链表（三大基本功）**
- [ ] **STM32 系统化**：时钟树、中断/NVIC、定时器、PWM、ADC+DMA、SPI、I2C、UART、低功耗模式
- [ ] **FreeRTOS**：任务、队列、信号量、互斥量、事件组
- [ ] **Linux 基础**：命令行、Makefile、交叉编译

### D. 半导体 —— 投递面

- [ ] 半导体物理与器件基础：PN 结、MOSFET、CMOS 工艺流程
- [ ] 工艺模块：光刻、刻蚀、薄膜沉积（CVD/PVD）、**CMP**、**电镀 ECP**、湿法清洗
- [ ] 量测 / 检测原理
- [ ] 已有背景：电化学测量、材料表征、MOF 合成 —— 直接对应湿法工艺与电化学量测

## 五、自我验收标准

不用「我懂了」判断，只用三档：

| 档次 | 定义 | 判定方式 |
|---|---|---|
| **L1 自测合格** | 不给资料、不给答案，限时内独立完成 | 闭卷卷子 / 自写测试用例 / 一键复现 |
| **L2 表达合格** | 能对白板讲清「为什么这么做」并给出数字 | 录音讲 3 分钟，对方能复述 |
| **L3 市场合格** | 陌生人看了简历或仓库，愿意给面试 | 面试邀请 / 内推 |

**判定原则：每一周只有做出「交付物」才算通过。没有交付物 = 这一周白过。**

### 最容易「假合格」的地方

| 假合格 | 真合格 |
|---|---|
| 网课看完 = 学会了 | 闭卷能重做，且能给别人讲明白 |
| HDLBits「看懂了答案」 | 题库提交通过 ≥ 30 题 |
| 用默认参数跑通 ORFS | 能说出每个关键参数的物理理由 |
| GDS 生成了 | 用 KLayout 打开看过，LVS clean，WNS 能解读 |
| 「WNS 收敛了」 | 能画出关键路径并指出瓶颈的物理成因 |
| 「看过 UVM 教程」 | 能独立搭一个 component 并跑通一个 case |
| 简历写了「熟悉数字后端」 | 有 5 个具体数字 + 能讲 3 分钟 |
| 投了 5 家等消息 | 海投 80–150 家，分层投递，逐家记录状态 |
